# Product Pitch

## Name

Milo

## One-sentence pitch

Milo is a protected web app that lets children use a parent-selected AI engine (ChatGPT or DeepSeek) under age-appropriate safety restrictions, when the official AI chat websites are blocked.

## Customer

Parents, schools, tutoring centers, and child-focused learning platforms that want the educational benefits of AI chat without giving minors unrestricted access to it.

## Why now

Children already want to use AI for homework and curiosity. Website blocking alone is too blunt: it blocks both risky and helpful use. Milo offers a controlled middle path.

## Differentiation

- Brand-neutral: the parent picks the underlying engine (ChatGPT or DeepSeek); Milo never reveals which one to the child.
- Assumes official AI chat websites are blocked for the child's device/account.
- Provides a protected replacement interface.
- Checks both input and output — not with a static keyword list, but with real moderation scoring (self-harm, sexual, violent, drug, and weapon content) whose severity thresholds shift by the child's age band.
- Uses a second AI call to judge paraphrased jailbreak/bypass attempts a keyword list would miss, alongside instant keyword detection for the obvious ones.
- Can explain sensitive topics in safer educational language instead of only blocking.
- Transparent, PIN-gated Parent Dashboard: every decision is logged, with stats and alerts.

## Future business model

- Parent subscription.
- School-managed classroom licenses.
- White-label API for child-safe learning apps.
